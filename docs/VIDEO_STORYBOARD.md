# 🎬 Snoo-Clues Hackathon Video Storyboard

This document outlines the scene-by-scene structure for the Snoo-Clues hackathon submission video.

## Concept: "The Sleuth's Digital Notebook"
**Target Category:** Best Daily Game / Best Use of GameMaker / Best UX
**Duration:** ~90 Seconds
**Music:** Noir Jazz / Lo-fi Detective Beats

---

### Scene 1: The Hook (0:00 - 0:10)
- **Visual:** Close-up of the "Snoo-Clues" logo. Fade into the Splash Screen background.
- **Audio:** Typewriter sound effects as text appears: "CASE #42: THE MISSING SUBREDDIT."
- **Action:** Mouse clicks "OPEN CASE FILE."
- **Narrative (Text/VO):** "Every day, a new mystery. Every day, a new target."

### Scene 2: The Core Loop (0:10 - 0:30)
- **Visual:** Full-screen gameplay of the notebook UI.
- **Action:**
  - Reveal Evidence #1: "Digital battlefield for pixels and passion."
  - Reveal Evidence #2: "Controllers, keyboards, and frame rates."
  - Reveal Evidence #3: "🎮 Primary hub for electronic entertainment."
- **Audio:** "Rustle" SFX on each reveal.
- **Narrative (Text/VO):** "Three pieces of evidence. One answer. Can you close the case?"

### Scene 3: The Interaction (0:30 - 0:45)
- **Visual:** Type "r/gaming" into the guess box.
- **Action:** Click "Submit." Mascot does a victory animation. "CASE CLOSED" stamp slams onto the screen.
- **Audio:** Loud "Stamp" or "Victory" chime.
- **Narrative (Text/VO):** "Identify the community. Build your streak. Rise through the ranks."

### Scene 4: The Features Montage (0:45 - 1:05)
- **Visual:** Fast cuts between:
  - **The Archives:** Showing the practice mode.
  - **Leaderboard:** Showing "Top Sleuths."
  - **Mascot Tips:** Clicking the lightbulb for a hint.
  - **UGC Form:** Quickly filling out "Submit a Case File."
- **Narrative (Text/VO):** "Endless practice in the Archives. Compete globally. Contribute your own mysteries."

### Scene 5: The Technical Edge (1:05 - 1:20)
- **Visual:** Split screen. Left side shows GameMaker mascot animations; Right side shows Devvit TypeScript code or Redis logic snippets.
- **Narrative (Text/VO):** "Built with a hybrid Devvit + GameMaker engine for seamless, high-performance daily play."

### Scene 6: The Call to Action (1:20 - 1:30)
- **Visual:** "Snoo-Clues" logo with link to the subreddit.
- **Text:** "PLAY NOW: r/SnooClues"
- **Narrative (Text/VO):** "The investigation is waiting. Snoo-Clues. Only on Reddit."
